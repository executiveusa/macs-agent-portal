# Product bar and lock

**User-approved bar:** the existing seven-client Agent MAXX V3 chat-first design. Familiar ChatGPT/Claude-style primary conversation; dashboards and settings in on-demand drawers, not persistent walls of data. Distinct company-specific suggested tasks for CROWN AND CORE, THP FLOORING, BUNNA RESTAURANT, MACS DIGITAL MEDIA, ASC3ND, 3X PLUMBERS, TANGLES AND LOCS. Real account and client permissions via Supabase Google login. MAXX executes authorized ICM workflows and shows source-backed proof, with safe voice and external agent ingress.

**Minimum viable production acceptance (not a narrow demo):** real authenticated operator signs in, changes between seven individually authorized clients, sees context-specific suggestions and per-client task history, gets real approval alerts and human-required action boundaries, can recover a client archive for at least 30 days, can use chat/voice, and can authorize at least one real ICM workflow with an audited receipt. Connections screen truthfully identifies what is/ isn't connected. 320/390/1440 screens accessible.

**Quality bar:** overall >=8.5; correctness, security, reliability each >=9; critical failures 0; unsupported completion claims 0; independently assessed against the approved chat-first prototype and user workflows. Build-only evidence is not product proof.

**Scope lock:** one revenue workstream (MACS authorized client operations/Bunna verified outcome), one platform (MAXX), one bounded experiment (Stacy's Instinct ingress); park new SaaS, separate CRM, other unrelated PRs.

**Owner authority:** no unreviewed production DB migrations, client outreach, spending, publication, destructive deletion or secret exposure. Production deployment needs documented independent evidence and explicit authorization; the user's implementation request is not blanket approval for unsafe changes.
