# BluSky Opportunity Ledger

Purpose: one living register for Stacy + Agent MAXX to track BluSky opportunities without confusing hypotheses with facts.

## Status vocabulary

- `seed` — worth asking about; little evidence.
- `research_more` — promising but missing material evidence.
- `ready_for_conversation` — relationship + problem + ask are clear enough for a human conversation.
- `pilot_authorized` — BluSky/Stacy approved a bounded test.
- `in_pilot` — test is active.
- `verified_value` — measured revenue, savings, recovery, or validated learning exists.
- `rejected` — not worth pursuing; record why.
- `parked` — valid idea, wrong time.

## Evidence labels

Use one or more on every material claim:
- `STACY_DIRECT` — Stacy personally observed/heard it.
- `BLUSKY_INTERNAL` — authorized internal data/source.
- `PUBLIC_VERIFIED` — current public source.
- `INFERENCE` — reasoned hypothesis from evidence.
- `UNKNOWN` — not yet established.
